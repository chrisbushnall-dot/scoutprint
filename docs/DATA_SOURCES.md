# Data sources and licence review

Reviewed 2026-08-29. This is an engineering assessment, not legal advice. A repository being public does not by itself grant permission to copy its data. Only sources with an identifiable permission basis are enabled. Every downloaded file receives a sidecar containing its URL, retrieval time, byte size, SHA-256 checksum, provider and licence.

## Recommended combination

1. Use the CC BY 4.0 Pappalardo/Wyscout release for the first complete big-five-league spatial proof of concept and Salah 2017/18.
2. Use StatsBomb Open Data where its richer event fields and expressly released competition coverage are valuable. Never imply the Bayer Leverkusen release is a complete Bundesliga population.
3. Use OpenFootball/CC0 for clearly labelled match-result coverage only.
4. Keep aggregate adapters logically separate and show `spatial_available = false` whenever only aggregate data exists.
5. Treat Understat, ambiguous Kaggle mirrors, and Football-Data.co.uk bulk automation as unavailable until permissions are unambiguous.

## Known free-data gap

No reviewed, clearly licensed free source supplies dense player event coordinates for all requested leagues over the last ten seasons. Current-player and “current young player” searching therefore cannot be complete under the zero-subscription constraint. The application exposes this gap rather than fabricating continuity. Provider adapters allow a properly licensed feed to be added later.
